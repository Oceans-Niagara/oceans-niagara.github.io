Resilient Edge Data Transit

Data Delivery in Challenging Environments

Oceans Niagara focuses on communications resilience for autonomous machines and distributed systems operating across Disconnected, Intermittent, and Low-Bandwidth (DDIL) networks.

Active Research: Zero-Retransmission Asset Sync

In large-scale field deployments—such as agricultural robotics, autonomous turf machinery, environmental sensor grids, and industrial rovers—patchy wireless links cause sustained packet loss. Standard acknowledgment-based protocols (TCP or ARQ pub/sub) trigger severe ACK/NACK storms when broadcasting large binary payloads to multiple nodes over constrained links.

We are prototyping a zero-retransmission distribution pipeline pairing Eclipse Zenoh with RaptorQ (RFC 6330) forward error correction. By streaming rateless mathematical droplets rather than sequential chunks, edge nodes can reconstruct full operational assets—such as runtime configurations, perception bounds, state models, or WASM execution routines—from any random subset of broadcast packets.

Core Architecture Pillars

Rateless Erasure Coding

RaptorQ fountain codes eliminate acknowledgment overhead. Receivers reconstruct complete binary payloads from any valid subset of droplets caught.

Self-Describing OTI

Every packet carries a 16-byte metadata prefix, ensuring drops of initial stream headers never prevent full recovery.

Decentralized Pub/Sub

Leverages Eclipse Zenoh for unified telemetry, remote commands, and inter-peer cache repair across ad-hoc radio meshes.

Atomic Edge Staging

Crash-proof append operations with explicit fsync boundaries protect edge nodes against sudden field power loss.
