Quick Play

How it works: Each character is unpacked into 8 binary bits (0s and 1s) and wrapped into a 2D grid (once you type 8+ characters). 0 blocks light and 1 lets it pass, forming the aperture on the left. Virtual white light shines through that mask and travels 25 mm: repeating bits interfere into sharp grids or bars, while irregular bits scatter light broadly, and Red/Green/Blue wavelengths bend at different angles to create color fringes. Note: this view is locked to binary bits in a 2D amplitude matrix. Switch to Simple View or Optical Bench to test UTF-8 byte values, phase-bending mode, laser wavelength, distance z, and full metrics.

Field Guide (what the metrics mean)
  • Fourier Power Slope (β) (how fast waves fade across scales) — 0 = white static, 1–2.5 = natural flow, >2.5 = ultra-smooth.
  • Input Fractal Dim (surface jaggedness of your data) — 1.0 = clean smooth shape; 2.0 = dense space-filling texture.
  • Light Caustic Dim (complexity of the projected light web) — Measures how intricately the beam splits at distance z.
  • Golden Ratio (φ) Match (alignment with 1.618:1 symmetry) — Checks dominant wave ratios (text) or frame shape (images).
  • Shannon Entropy (unpredictability per character or pixel) — Low = few repeated symbols; high = maximum variety.
  • Spectral Entropy (evenness across wave speeds) — 0 = single pure tone or ring; 1 = flat white noise.
  • Compressibility (deflate) (how tightly repeating sequences shrink) — Near 0 = heavy repetition; near 1 = incompressible static.
  • Scintillation Index (σ²) (sharpness of bright light twinkling) — 0 = even glow; >1 = intense focused caustics.
  • CIE Spectral Color (frequency balance as visible light) — Slow waves glow warm red; fast jitter shifts violet.
  • Signal Regime (overall pattern family) — Groups inputs into Ordered / Repetitive, Structured / Natural, or Chaotic / Static.
